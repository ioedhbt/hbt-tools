# guide/

Local preview: `pip install -r requirements.txt && mkdocs serve` (run from
this directory), then open http://127.0.0.1:8000.

Screenshots come from the capture harness — see `_harness/README.md` for how
they're made and regenerated.

Translation files are named `<page>.zh-TW.md` next to the English
`<page>.md`; screenshots are shared and never duplicated per language.
