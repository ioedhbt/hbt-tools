# 首次曝光

在裸晶片上寫下第一個圖案：沒有標記，不對準任何已存在的東西，寫入場只是鋪滿
晶片尺寸的網格並置中於晶片上。本頁走一遍 **首次曝光 (First Exposure)** 模式，
使用 `first_exposure.gds`（六個元件，基極焊墊／射極指狀電極／集極焊墊各自
在自己的 datatype 上，另外還有四個對準標記，留給接下來的
[二次曝光](second-exposure.md)使用）。

如果這是你第一次來這一頁，請先讀[電子束微影計算機基礎](index.md)。
**下面每個欄位都維持預設值，除了要你輸入的那兩個位置**，其他一律由遮罩
自動算出或不用理會；每張截圖都會註明是哪一種。

## 1. 輸入你實際找到的晶片角落

在動遮罩之前，**夾具中的晶片位置 (Chip Position in the E-beam Holder)**
必須符合晶片今天在夾具裡的實際位置，而不是套用固定的預設值。假設你在
載台位置 (105.000, 115.000) mm 下找到晶片的左下角：

1. 把這組數字輸入 **左下 (BL) (Bottom Left (BL))** 的 x/y 欄位。

接著找到右上對準標記，位於晶片右上角附近，在這片遮罩上的設計座標是
(1900, 1900) µm，並讀出其載台位置為 (107.000, 117.000) mm：

2. 把這組數字輸入 **右上 (TR) (Top Right (TR))** 的 x/y 欄位。

![BL 與 TR 角落欄位已輸入；TL 與 BR 已自動算出並禁用](../assets/ebl/first_corners.png)

**左上 (TL)** 與 **右下 (BR)** 呈灰色禁用，由系統自動算出，搭配 **形狀
(Shape) = 矩形 (Rectangular)** 與 **可編輯對角 (Editable diagonal) = BL /
TR**（皆為預設值），另一組對角會自動推算。不要去動它們。

## 2. 載入遮罩並選圖層

3. 上傳 `first_exposure.gds`，然後把 **要曝光的圖層 (Layer to expose)**
   設為 `L1/D2`（6 個多邊形），也就是射極指狀電極，這是這片遮罩上間距最
   細的特徵，也是最需要注意劑量的部分。

![GDS 遮罩區塊：已載入 first_exposure.gds，選取圖層 L1/D2](../assets/ebl/first_layer.png)

這片遮罩把基極焊墊、射極指狀電極、集極焊墊分別放在不同的 datatype 上
（`L1/D1`、`L1/D2`、`L1/D3`）。每個都要獨立曝光一次。本頁只走一遍其中一個；
其他兩個用相同的角落與 Cel Origin 重複即可。

## 3. 網格幾何參數維持自動

4. 在 **曝光流程 (Workflow)** 底下選 **首次曝光 (First Exposure)**。
   **job1 中的 Cel 原點 (mm) (Cel Origin (mm) in job1)**、**job1 中的網格
   數量 (Grid Count in job1)**（Nx、Ny）與 **job3 中的位移 (mm) (Shift
   (mm) in job3)** 全部由遮罩的邊界框與你在步驟一設定的晶片角落自動算出，
   三個都不要動。

![遮罩圖層尺寸說明文字與三張自動算出的卡片](../assets/ebl/first_inputs.png)

卡片上方的說明文字寫出了完整的運算過程：這個遮罩圖層是 0.505 × 0.310
mm，在預設 Cel Origin (9.700, 9.700) 下需要 4×2 個 0.600 mm 的區塊才能
完全覆蓋。改變圖層、晶片角落，或在 **左側電腦設定 (Left Computer Setup)**
裡改變晶片尺寸，這三張卡片都會重新計算，這就是為什麼它們設計成自動而不是
手動輸入。

## 4. 檢查圖

![晶片（藍色）、4×2 網格（橘色）與跨兩個區塊的遮罩](../assets/ebl/first_plot.png)

晶片矩形現在反映步驟一的角落，網格置中於其上，射極遮罩（在這個比例下幾乎
看不見，六條寬 4, 5 µm 的細線）落在八個區塊中的兩個裡。

## 5. 設定劑量並讀出時間

5. 在 **曝光時間計算 (Time Calculator)** 底下，讓 **劑量時間 (μs / dot)
   (Dose time (μs / dot))** 與 **載台移動時間 (s / grid) (Stage movement
   time (s / grid))** 維持預設值（2.000、15.00），然後按 **計算時間
   (Calculate time)**。

![按下計算前的曝光時間計算輸入](../assets/ebl/first_time_in.png)

![按下計算後的明細與預估時間](../assets/ebl/first_result.png)

8 個區塊裡只有 2 個含有射極幾何圖案（**有效網格數 (Active grids): 2 /
8**）；其餘的會被跳過，所以曝光與載台移動時間只計入真正有圖案的區塊。
**預估時間 (Estimated Time)** 就是要寫上工作單的數字，見[工作編號表](job-sheet.md)
依序看本頁與[劑量時間測試](dose-test.md)的每個數字各自落在 JEOL 系統的
哪個欄位。
