# HBT Tools Guide

HBT Tools is a Streamlit portal for RF S-parameter de-embedding and
small-signal-model extraction, DC curve analysis, and an e-beam lithography
calculator. Pick a section below.

<div class="grid cards" markdown>

-   :satellite: **RF measurement**

    ---

    De-embed S-parameters, extract small-signal models, and simulate or
    fit topologies.

    [:octicons-arrow-right-24: Start with RF at a glance](rf/at-a-glance.md)

-   :zap: **DC measurement**

    ---

    Batch-convert measurement files, view B1500A/4155A curves, and run
    TLM analysis.

    [:octicons-arrow-right-24: Start with Measurement data multi-process](dc/multi-process.md)

-   :triangular_ruler: **E-beam lithography**

    ---

    Compute chip positions and set up a JEOL ELS-7000 exposure job.

    [:octicons-arrow-right-24: Start with EBL calculator basics](ebl/index.md)

</div>
