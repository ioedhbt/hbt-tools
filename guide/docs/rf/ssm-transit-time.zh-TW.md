# 模型萃取：渡越時間

τ_total 對 1/I 作圖，截距給出 τ_B + τ_C，斜率給出 C_JE。這需要多個偏壓
點，因此開始前請先載入整組掃描資料。

開啟 **📊 Interactive Parameter Extraction**，然後選擇
**Cje / τB+τC / τCC / τE from 1/(2πf_T) vs 1/I_C fit**。

所擬合的關係式為

$$\frac{1}{2\pi f_T} = \tau_B + \tau_C + \frac{\eta kT}{qI_C}C_{JE}
  + \left(R_C + R_{EE} + \frac{\eta kT}{qI_C}\right)C_{BC}$$

因此截距為 τ_B + τ_C，斜率則帶有 C_JE。

## 使用 I_E = I_C + I_B

該欄標示為 **IC (mA)**，且 Cheng 的公式使用集極電流。請改為輸入**射極**
電流：I_E = I_C + I_B。

![渡越時間表，每個檔案列出 fT 與 tau_total，IC (mA) 欄以方框標出](../assets/ssm/transit_ic_table.png)

1. 將每一列的 **IC (mA)** 欄改寫為該偏壓點的 I_C + I_B。

以示範元件為例：

| 檔案 | I_C | I_B | 輸入值 | f_T | τ_total |
|---|---|---|---|---|---|
| `ib80u` | 1.600 mA | 80 µA | **1.680** | 1.607 GHz | 99.03 ps |
| `ib120u` | 2.928 mA | 120 µA | **3.048** | 1.869 GHz | 85.17 ps |
| `ib160u` | 4.418 mA | 160 µA | **4.578** | 2.074 GHz | 76.74 ps |
| `ib200u` | 6.075 mA | 200 µA | **6.275** | 2.268 GHz | 70.17 ps |
| `ib240u` | 7.859 mA | 240 µA | **8.099** | 2.330 GHz | 68.31 ps |
| `ib280u` | 8.018 mA | 280 µA | **8.298** | 2.455 GHz | 64.84 ps |

取消勾選任何不想納入擬合的檔案。

## 判讀擬合結果

![tau_total 對 1/I_C 圖，含擬合線，斜率 69.05 ps mA，截距 59.59 ps](../assets/ssm/transit_tau_fit.png)

- **截距**：59.5923 ps，是量測延遲中不隨電流縮小的部分。
- **斜率**：69.05 ps·mA，由此可求出 C_JE。

這個截距還不是 τ_B + τ_C。集極充電項 (R_C + R_EE + r_E)·C_BC 仍須扣除，
這正是下方輸入欄的用途。

## 代入實際的接觸電阻

![輸入列，方框標出 Re-REE、Rc 與 Cbc，以及計算出的 slope、intercept、Cje 與 tauB+tauC](../assets/ssm/transit_inputs_outputs.png)

**輸入值（預設取自此檔案的萃取結果） (Inputs (defaults from this file's
extraction))** 一開始為 Re — REE = `0.0000`，Rc = `0.0000`。除非
[接觸電阻步驟](ssm-access-r.md)已經執行過，否則這些預設值都是錯的。請
輸入方框標出的三個數值：

| 欄位 | 數值 | 來源 |
|---|---|---|
| **Re — REE (Ω)** | 64.3966 | Z-parameter 擬合 |
| **Rc (Ω)** | 19.0178 | Cold-HBT |
| **Cbc total (fF)** | 484.2610 | T 模型萃取 |

除非你有 Gummel 擬合另有指示，否則將 η 保留在 1.000，T 保留在 300.0。

代入之後答案會有很大的變化：**τ_B + τ_C 從 59.59 ps 降到
19.1980 ps。** 截距中剩下的部分全部都是集極充電。

### 拆分 τ_B 與 τ_C

**Split τ_B / τ_C** 這一列會用假設的平均集極速度拆分總和。以 InP 預設值
W_C = 120 nm 與 v_c = 4.000e+7 cm/s 計算：

- **τ_C = 0.1500 ps**
- **τ_B = 19.0480 ps**

**用這兩個值取代 Cheng 的 τB 與 τC。**[本質模型頁](ssm-intrinsic.md)上的
解析萃取，對此元件給出 τB = 10.7654 ps、τC = −6.7695 ps，而負的集極
渡越時間並非物理上合理的答案。渡越時間擬合使用六個偏壓點與量測到的
f_T，因此是可信的數字。

下方逐檔案表格顯示，代入修正後的輸入值後，每個檔案落在哪個位置：

![逐檔案推導延遲表，列出每個檔案的 IC、rE、tauCC、tauE 與量測 tau_total](../assets/ssm/transit_perfile.png)

這些萃取值僅供參考讀值。它們**不會**自動回饋到模型擬合中，若要讓它們
進入最終出貨的模型，需手動輸入到微調面板。

## 該用哪一種電流

Cheng 的預設是 I_C，本頁也是依此建構。改用 I_E 會使每個點依
I_B/(I_C·I_E) 向左偏移，主要讓曲線低電流端變陡。

請使用 I_E。所擬合的延遲是射極到集極的總渡越時間，而在 InP HBT 掃描的
低電流端，I_B 佔 I_C 的百分之幾，足以彎曲決定截距的那些點。當 β 很大且
只關心斜率時，Cheng 的 I_C 形式沒有問題；但當你要的是 τ_B + τ_C 時，
它就是較弱的選擇。

不論選哪一種，每一列都要一致使用。若部分列用 I_C、部分列用 I_E，等於是
對兩種不同的量擬合同一條線。

## 跨檔案的 τ_total

多檔案區段會針對每個勾選的檔案，一次擬合出一組共用的 τ_total 參考值，
上表中的數字即由此而來。勾選不同子集合，可以看出單一偏壓點對擬合結果的
影響有多大。若拿掉一個點就讓截距大幅移動，代表掃描範圍太短。
