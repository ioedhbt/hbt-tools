# B1500A Excel viewer

Plots B1500A curves and extracts DC parameters from them. Sidebar
**DC Measurement → DC Analysis**, page selector at the top set to
**B1500A Excel Viewer** (the other option is [TLM Analysis](tlm.md)).

The four screenshots below come from the four curated demo files in
`guide/_data/dc/` (one BC diode, one BE diode, one Gummel, one Family, see
that folder's `CHOICES.md` for why each was picked), run through
[Measurement Data Multi-Process](multi-process.md) and handed off rather
than uploaded by hand, the viewer only takes `.xlsx`, and hand-off is the
fastest way to get there. Uploading your own `.xlsx` file(s) works the same
way; the uploader in step 1 below takes over as soon as you drop a file on
it.

## Arriving here

1. After a hand-off, the page opens with a banner and the received files
   already in the pickers below. Pick which uploaded/received file to view,
   then the sheet inside it if it has more than one, then the curve type.

   ![Received from Multi-Process, file and data-type pickers](../assets/dc/b_handoff.png)

Data type defaults from the filename (`Diode` for BE/BC, `Gummel`,
`Family`) but is a plain dropdown, change it if the guess is wrong.

## Curve types

### BC / BE diode

Plots `|I|` on a log axis against the swept voltage. The **η window**, two numbers or a drag-select on the plot, sets the voltage range the
ideality fit uses.

![BC diode extracted parameters](../assets/dc/b_bc_params.png)
![BC diode I–V](../assets/dc/b_bc_plot.png)

- **Ideality factor, η**: slope of a semilog fit of `I` vs `V` inside the
  η window, converted through `q/(slope·k·T)` at T = 300 K. η ≈ 1 is
  diffusion-dominated, η → 2 is recombination-dominated.
- **Saturation current, Is**: the y-intercept of that same semilog fit.
- **Knee / turn-on voltage**: linear extrapolation of the steep forward
  region back to `I = 0`.
- **BC/BE resistance**: chord resistance ΔV/ΔI between the two ends of the
  η window (labeled by whichever of "bc"/"be" appears in the file name).
- **Forward current @ V** / **Leakage current @ V**, the two readout
  voltages are separate number inputs above the metrics; move them to read
  the curve anywhere.
- **Rectification ratio**: forward current at `+|V|` divided by reverse
  current at `-|V|`, using the smaller of the sweep's two endpoint
  magnitudes.

The BC diode above (40×40 µm, `guide/_data/dc/BC diode […].csv`) reads
η = 4.07, Is = 36.4 µA, knee = 0.353 V, BC resistance = 82.3 Ω. The BE
diode (60×60 µm) reads a much more ideal η = 1.25, Is = 18.7 pA, different
junction, different physics, same page.

![BE diode extracted parameters](../assets/dc/b_be_params.png)
![BE diode I–V](../assets/dc/b_be_plot.png)

### Gummel

![Gummel ideality](../assets/dc/b_gummel_eta.png)
![Gummel current gain](../assets/dc/b_gummel_beta.png)
![Gummel plot — Ic, Ib, β](../assets/dc/b_gummel_plot.png)

Plots Ic and Ib on a shared log axis against Vb, plus β = Ic/Ib on a
second linear axis. Same η-window control as the diode pages, applied to
both Ic and Ib independently:

- **Collector / base ideality, η(Ic) / η(Ib)**: same semilog-fit method as
  the diode page, one fit each for Ic and Ib.
- **Maximum gain, β(max)**: peak of Ic/Ib over the sweep, plus the Vb and
  Ic where it occurs.

The demo file (60×60 µm) reads η(Ic) = 0.99, η(Ib) = 1.40, β(max) = 5.6 at
Vb = 0.780 V.

### Ic-Vc family

![Family output-region parameters](../assets/dc/b_family_outreg.png)
![Family I–V](../assets/dc/b_family_plot.png)

One Ic-vs-Vc curve per Ib step. Controls and readouts:

- **Rsat window**: a Vc range (drag-select or number inputs) fit on the
  *highest-Ib* curve only.
- **Saturation (output) resistance**: `1/slope` of a linear fit of Ic vs
  Vc inside that window.
- **Early voltage, |VA|**: magnitude of that same fit's x-intercept.
- **Knee voltage**: Vc where Ic first reaches 90% of its saturation value
  (mean Ic over the top 20% of the sweep).

Hovering a curve shows its own DC gain β and offset voltage (Ic
zero-crossing) in a tooltip, the two sections below summarize both across
every curve on the plot:

![Offset voltage](../assets/dc/b_family_offset.png)
![Transconductance](../assets/dc/b_family_gm.png)

- **Average offset voltage**: mean Ic zero-crossing over curves that
  actually cross zero.
- **Peak transconductance, gm(max)**: `gm = Ic/Vt` (Vt = kT/q at the
  temperature you set) evaluated at each curve's saturation Ic, first-order
  and assuming ideal exponential Ic(Vbe); expand **Per-curve gm table** for
  the number behind every step.

The demo file (4×10 µm, Vc swept 0, 4 V) reads Rsat = 5,165 Ω,
|VA| = 10.98 V, knee = 2.560 V, average offset = 655.5 mV,
gm(max) = 109 mS.

## Other controls

- **Drag-select on any plot** sets the same window the number inputs
  above it do (η window, Rsat window), the two are linked either
  direction.
- Uploads persist across a page-switch to TLM Analysis and back; use the
  **Clear** button next to the "previously uploaded" caption to drop them,
  or **🗑️ Clear received data** to drop a hand-off.
