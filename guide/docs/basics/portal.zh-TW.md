# 入口網站

如何開啟入口網站、登入並切換語言。

## 首頁畫面

首頁以卡片列出每個工具，並依量測領域分組。

![首頁畫面，工具卡片依領域分組](../assets/basics/home_cards.png)

各分組簡述：

- **高頻量測 (RF Measurement)**：去嵌入 S 參數、萃取小訊號模型、正向模擬或擬合。
- **製程 (Process)**：電子束微影計算機與 HBT 製程流程圖解。
- **元件模擬 (Device Simulation)**：比對模擬 Gummel 圖與參考資料。
- **直流量測 (DC Measurement)**：B1500A 與 HP4155A 曲線檢視器。
- **資料處理 (Data Processing)**：為 DC 工具批次轉換量測檔案。

點選卡片上的**開啟 (Open)**，或使用側邊欄，即可進入工具。

## 側邊欄

側邊欄是切換工具的地方。收合它可讓主要內容有更多空間，或從取代它的漢堡選單控制項重新開啟。

1. 點選側邊欄頂端的 **«** 將其收合。

    ![側邊欄頂端的 « 收合控制項](../assets/basics/sidebar_collapse.png)

2. 側邊欄收合後，點選左上角出現的 **»** 控制項即可重新開啟。

    ![重新開啟已收合側邊欄的 » 控制項](../assets/basics/sidebar_reopen.png)

## 語言切換

1. 點選右上角的 **English** / **中文** 切換整個入口網站。側邊欄標籤、頁面標題與內文都會一併切換。

    ![每頁右上角的 RAM 徽章與語言切換](../assets/basics/top_right_controls.png)

## RAM 徽章

語言切換左側的長條（上圖標示 1）顯示伺服器端 RAM 使用量：`已用 / 上限 GB`，每 10 秒更新一次。超過容器記憶體上限的 60% 會轉為琥珀色，超過 85% 轉為紅色。

這與上傳有關：應用程式將單一上傳檔案上限設為 350 MB
（`.streamlit/config.toml` 的 `maxUploadSize`），這是即使最壞情況下的 GDS
光罩結構仍能保持在容器可用記憶體餘裕內的最大檔案大小。超過此上限的檔案會收到訊息並被拒絕，而不會導致當機；電子束微影計算機另外會依當下實際可用的
RAM 動態調整自身的解析預算，因此同一個檔案在容器閒置時可被接受，在容器忙碌時則可能被拒絕。

!!! tip
    透過 `LAUNCH_Tool.py` 在本機執行時，上傳上限會改為依你工作站 RAM
    的一部分計算，而不是固定的 350 MB。

## 密碼驗證

已部署的入口網站會在顯示任何內容前要求輸入密碼；透過 `LAUNCH_Tool.py`
在本機啟動則會完全略過這個畫面。
